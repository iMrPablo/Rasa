# درباره پروژه

## معرفی جامع
این پروژه یک سیستم پیشرفته و حرفه‌ای مبتنی بر معماری **MVC** (Model-View-Controller) است که با هدف ایجاد ساختاری منظم، قابل نگهداری، مقیاس‌پذیر و مدرن توسعه یافته است. این فریم‌ورک سبک وزن PHP با رعایت اصول SOLID و بهترین روش‌های برنامه‌نویسی طراحی شده است تا توسعه‌دهندگان بتوانند به سرعت و با کیفیت بالا اپلیکیشن‌های وب قدرتمند ایجاد کنند.

### ویژگی‌های کلیدی
- ✅ **معماری MVC استاندارد:** جداسازی کامل لایه‌های داده، منطق و نمایش
- ✅ **ساختار ماژولار:** قابلیت توسعه و افزودن ماژول‌های جدید به سادگی
- ✅ **امنیت بالا:** پیاده‌سازی اصول امنیتی در تمام لایه‌ها
- ✅ **پرفورمنس بهینه:** کدنویسی تمیز و بهینه برای سرعت اجرای بالا
- ✅ **قابلیت توسعه آسان:** مستندات کامل و ساختار خوانا
- ✅ **پشتیبانی از تم تاریک و روشن:** دارای قابلیت Dark Mode و Light Mode برای تجربه کاربری بهتر
- ✅ **ریسپانسیو:** سازگار با تمام دستگاه‌ها و اندازه‌های صفحه

**مهارت‌های کلیدی:**

- بهینه‌سازی پرفورمنس و امنیت

## ساختار پروژه
```
/workspace
├── app/
│   ├── Controllers/    # کنترلرهای پروژه - مدیریت درخواست‌ها و منطق کسب‌وکار
│   ├── Models/         # مدل‌های داده - ارتباط با پایگاه داده و مدیریت داده‌ها
│   └── Views/          # ویوها (نمای‌ها) - نمایش داده‌ها به کاربر با پشتیبانی از Dark/Light Mode
├── config/             # فایل‌های پیکربندی - تنظیمات اصلی سیستم
├── public/             # فایل‌های عمومی و ورودی اصلی - شامل CSS، JS و تصاویر
└── index.php           # نقطه شروع برنامه - Router اصلی
```

## معماری MVC به تفصیل

### 📊 Model (مدل)
لایه مدل مسئولیت مدیریت داده‌ها و منطق کسب‌وکار را بر عهده دارد:
- ارتباط با پایگاه داده
- اعتبارسنجی داده‌ها
- پردازش منطق تجاری
- ارائه داده‌ها به کنترلر

### 🎨 View (نما)
لایه نما وظیفه نمایش داده‌ها به کاربر را دارد:
- قالب‌بندی و نمایش اطلاعات
- **پشتیبانی از تم تاریک (Dark Mode) و روشن (Light Mode)**
- رابط کاربری ریسپانسیو و مدرن
- تعامل با کاربر

### 🎯 Controller (کنترلر)
لایه کنترلر واسط بین Model و View است:
- دریافت و پردازش درخواست‌های کاربر
- فراخوانی مدل‌های مناسب
- انتخاب ویوی مناسب برای نمایش
- مدیریت جریان برنامه

## قابلیت Dark Mode و Light Mode
این پروژه مجهز به سیستم تغییر تم هوشمند است که به کاربران امکان می‌دهد بین حالت‌های زیر انتخاب کنند:

### 🌞 حالت روشن (Light Mode)
- پس‌زمینه سفید و متن تیره
- مناسب برای استفاده در محیط‌های پرنور
- کاهش خستگی چشم در طول روز

### 🌙 حالت تاریک (Dark Mode)
- پس‌زمینه تیره و متن روشن
- مناسب برای استفاده در شب و محیط‌های کم‌نور
- کاهش مصرف انرژی در نمایشگرهای OLED
- ظاهر مدرن و جذاب

### نحوه استفاده
کاربران می‌توانند از طریق دکمه تغییر تم در interface پروژه، بین حالت‌های مختلف جابجا شوند. تنظیمات انتخاب شده در Local Storage مرورگر ذخیره شده و در بازدیدهای بعدی حفظ می‌شود.

## تکنولوژی‌های مورد استفاده
- **PHP 8+** - زبان برنامه‌نویسی سمت سرور
- **MVC Architecture** - الگوی طراحی معماری
- **HTML5 & CSS3** - ساختار و استایل‌دهی
- **JavaScript (ES6+)** - تعاملات سمت کاربر
- **LocalStorage API** - ذخیره‌سازی تنظیمات تم

## نصب و راه‌اندازی
1. کلون کردن مخزن پروژه
2. تنظیم فایل‌های پیکربندی در پوشه `config`
3. تنظیم دسترسی‌های لازم برای پوشه‌ها
4. بارگذاری پروژه روی سرور PHP
5. دسترسی از طریق مرورگر
