# درباره پروژه

## معرفی جامع
این پروژه یک سیستم پیشرفته و حرفه‌ای مبتنی بر **معماری ساخت‌یافته (Structured Architecture)** است که با هدف ایجاد ساختاری منظم، قابل نگهداری، مقیاس‌پذیر و مدرن توسعه یافته است. این اپلیکیشن سبک‌وزن PHP با رعایت اصول Clean Code و بهترین روش‌های برنامه‌نویسی طراحی شده است تا توسعه‌دهندگان و کسب‌وکارها بتوانند بدون نیاز به پایگاه‌داده‌های سنگین، به سرعت و با کیفیت بالا یک سیستم مدیریت فروش قدرتمند را راه‌اندازی کنند.

### ویژگی‌های کلیدی
- ✅ **معماری ساخت‌یافته و یکپارچه:** جداسازی منطقی لایه‌های داده، API و رابط کاربری در یک ساختار منسجم و بدون پیچیدگی‌های اضافی
- ✅ **سیستم چندزبانه (i18n):** پشتیبانی کامل از ۶ زبان با تغییر خودکار چیدمان (RTL/LTR)
- ✅ **چند واحد پولی:** پشتیبانی از ۵ واحد پولی بین‌المللی با قابلیت قفل‌شدن پس از نصب
- ✅ **سیستم نصب‌کننده (Installer):** راه‌اندازی اولیه آسان و تعاملی
- ✅ **مدیریت مالی پیشرفته:** محاسبه خودکار مالیات بر ارزش افزوده (VAT) و تخفیف‌های درصدی/مبلغی
- ✅ **پشتیبانی از تم تاریک و روشن:** دارای قابلیت Dark Mode و Light Mode برای تجربه کاربری بهتر
- ✅ **ریسپانسیو و مدرن:** منوی ناوبری شناور (Island Nav) و سازگار با تمام دستگاه‌ها

## ساختار پروژه
برخلاف فریم‌ورک‌های سنگین MVC، این پروژه از یک معماری ساخت‌یافته و چابک پیروی می‌کند که نیاز به دیتابیس را حذف کرده است:

```text
/workspace
├── index.php           # فایل اصلی برنامه (شامل منطق Backend، API و رابط کاربری Frontend)
└── rasa_data/          # پوشه ذخیره‌سازی داده‌ها (ایجاد شده به صورت خودکار)
    ├── .htaccess       # فایل امنیتی برای جلوگیری از دسترسی مستقیم وب به فایل‌های JSON
    ├── settings.json   # تنظیمات فروشگاه، زبان، پول، تم، مالیات و وضعیت نصب
    ├── categories.json # لیست دسته‌بندی‌ها
    ├── products.json   # لیست محصولات
    ├── invoice.json    # پیش‌نویس فاکتور فعلی (Draft)
    └── sales.json      # تاریخچه کامل فروش‌ها و فاکتورهای ثبت شده
```

## معماری ساخت‌یافته به تفصیل

### 💾 لایه مدیریت داده (Data Layer)
- استفاده از فایل‌های **JSON** برای ذخیره‌سازی سبک، سریع و بدون نیاز به نصب و پیکربندی پایگاه داده (Database-less).
- استفاده از `LOCK_EX` در PHP برای جلوگیری از تداخل در زمان خواندن و نوشتن همزمان.
- ایمن‌سازی پوشه داده‌ها با فایل `.htaccess`.

### ⚙️ لایه منطق تجاری و API (Business Logic & API Layer)
- توابع مجزا و بهینه برای محاسبات پیچیده تقویم جلالی (الگوریتم‌های دقیق تبدیل تاریخ).
- تولید آیدی‌های تصادفی امن (`random_bytes`) و شماره سریال‌های ترتیبی.
- مدیریت درخواست‌های AJAX از طریق یک Endpoint واحد (`?api=1`) با متدولوژی REST-like.
- اعتبارسنجی دقیق ورودی‌ها و جلوگیری از Injection.

### 🎨 لایه نمایش (Presentation Layer)
- رابط کاربری تک‌صفحه‌ای (SPA-like) با استفاده از **Vanilla JavaScript** بدون نیاز به فریم‌ورک‌های سنگین.
- مدیریت State متمرکز در سمت کلاینت.
- سیستم ترجمه (i18n) پویا با استفاده از دیکشنری‌های JavaScript و تغییر آنی DOM.
- استفاده از **CSS Variables** برای پیاده‌سازی بی‌نقص تم‌های تاریک و روشن.

## قابلیت Dark Mode و Light Mode
این پروژه مجهز به سیستم تغییر تم هوشمند است که تنظیمات آن در سمت سرور (فایل `settings.json`) ذخیره می‌شود تا در تمام دستگاه‌های کاربر اعمال گردد:

### 🌞 حالت روشن (Light Mode)
- پس‌زمینه گرادیانت روشن و کارت‌های سفید
- مناسب برای استفاده در محیط‌های پرنور و اداری

### 🌙 حالت تاریک (Dark Mode)
- پس‌زمینه تیره (Deep Blue/Dark) با کنتراست بهینه
- کاهش خستگی چشم و مصرف انرژی در نمایشگرهای OLED
- ظاهر مدرن و جذاب با سایه‌های نئونی و Glassmorphism در منوی ناوبری

## نصب و راه‌اندازی
1. آپلود فایل `index.php` روی هاست یا سرور محلی (نیاز به PHP 8+).
2. مراجعه به آدرس پروژه در مرورگر.
3. تکمیل **ویزارد نصب** (انتخاب زبان، واحد پول و تقویم).
4. سیستم به صورت خودکار پوشه `rasa_data` را ایجاد و آماده استفاده است!

## مجوز و حقوق
تمامی حقوق مادی و معنوی این پروژه متعلق به **آقای پابلو** می‌باشد.
هرگونه کپی‌برداری، توزیع مجدد یا استفاده تجاری بدون اجازه کتبی طراح ممنوع است.
