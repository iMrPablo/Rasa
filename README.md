# 🚀 درباره پروژه (نسخه 3.0)
## معرفی جامع
این پروژه یک سیستم پیشرفته و حرفه‌ای مدیریت فروش، انبارداری و مرجوعی مبتنی بر معماری ساخت‌یافته (Structured Architecture) است که با هدف ایجاد ساختاری منظم، قابل نگهداری، مقیاس‌پذیر و مدرن توسعه یافته است. این اپلیکیشن سبک‌وزن PHP با رعایت اصول Clean Code طراحی شده تا توسعه‌دهندگان و کسب‌وکارها بتوانند بدون نیاز به پایگاه‌داده‌های سنگین، یک سیستم قدرتمند، **چندزبانه (۸ زبان)** و **چند ارزی (۷ واحد پولی)** را راه‌اندازی کنند. نسخه ۳ با تمرکز بر **گسترش بین‌المللی**، **تحلیل داده‌ها** و **بهبود تجربه کاربری (UX)** منتشر شده است.

## ✨ ویژگی‌های کلیدی و جدید در نسخه 3.0
✅ **گسترش بین‌المللی (Global Expansion):** پشتیبانی از ۸ زبان (شامل چینی و روسی) و ۷ واحد پولی (شامل یوان و روبل) با بومی‌سازی کامل نام ماه‌های شمسی.
✅ **سیستم انبارداری تحلیلی:** افزودن آمار ارزش کل انبار، تعداد موجودی و داشبورد کالاهای کم‌موجود.
✅ **سیستم مرجوعی هوشمند:** تولید شماره سریال خودکار مرجوعی (RET-000001)، کنترل دقیق مقدار قابل مرجوعی و جلوگیری از مرجوعی بیش از حد.
✅ **ساعت و تقویم زنده جهانی:** تنظیم خودکار Timezone بر اساس زبان انتخابی (پشتیبانی از شانگهای، مسکو، نیویورک، لندن و...).
✅ **حالت تقویم ترکیبی (Both):** امکان نمایش همزمان تاریخ شمسی و میلادی در فاکتورها و گزارش‌ها.
✅ **پرفروش‌ترین محصولات (Top Products):** رتبه‌بندی محصولات بر اساس تعداد فروش و درآمد با نمودار بصری.
✅ **جستجوی پیشرفته فاکتور:** امکان جستجو در تاریخچه فاکتورها بر اساس شماره، آیدی و **نام مشتری**.
✅ **افزودن سریع محصول (Quick Add):** چیپست‌های افزودن سریع با قابلیت فیلتر بر اساس دسته‌بندی.
✅ **شخصی‌سازی چاپ:** امکان تنظیم متن پاورقی (Footer Message) برای فاکتورهای چاپی.
✅ **دسترسی‌پذیری (Accessibility):** پشتیبانی از `prefers-reduced-motion` برای کاربرانی که به انیمیشن حساس هستند.
✅ **مسدودسازی موبایل (Block Mobile):** محدود کردن دسترسی به پنل فقط برای دستگاه‌های دسکتاپ با صفحه اختصاصی.
✅ **منوی کشویی موبایل (Drawer):** منوی اختصاصی و زیبا برای دستگاه‌های موبایل با نمایش اطلاعات دستگاه.

### 🔥 نسخه 2.4 - نسخه انبارداری و هوشمند

**طراح و توسعه‌دهنده:** آقای پابلو

* 📑 **خروجی گزارش‌ها به Excel (CSV):** دانلود گزارش‌های فروش با فرمت CSV و پشتیبانی کامل از UTF-8.
* 🎨 **ارتقای رابط کاربری (UI/UX):** افزودن منوی کناری (Side Island) برای دسترسی سریع به بخش‌های انبار و مرجوعی.

### 🌐 نسخه 3.0 - نسخه جهانی، تحلیلی و یکپارچه (فعلی)
**📅 تاریخ انتشار:** مهر ۱۴۰۵
**طراح و توسعه‌دهنده:** آقای پابلو

✨ **قابلیت‌های جدید و ارتقاهای چشمگیر در نسخه 3.0:**
* 🌍 **گسترش بین‌المللی (Global i18n):** افزودن زبان‌های **چینی (ZH)**، **روسی (RU)** و **انگلیسی بریتانیایی (EN_GB)** به همراه بومی‌سازی کامل نام ماه‌های شمسی برای تمام زبان‌ها.
* 💰 **پشتیبانی از ارزهای جدید:** افزودن **یوان چین (CNY)** و **روبل روسیه (RUB)** به لیست واحدهای پولی (مجموعاً ۷ ارز).
* 📊 **داشبورد تحلیلی انبار:** نمایش **ارزش ریالی/ارزی کل انبار**، مجموع تعداد موجودی و لیست هوشمند کالاهای کم‌موجود.
* 🏆 **پرفروش‌ترین محصولات (Top Products):** رتبه‌بندی بصری محصولات بر اساس تعداد فروش و درآمد کل با نمودار پیشرفت.
* 🔁 **سیستم مرجوعی هوشمند:** تولید خودکار شماره سریال مرجوعی (`RET-000001`)، محاسبه دقیق مقدار باقی‌مانده قابل مرجوعی و جلوگیری از خطای مرجوعی بیش از حد.
* 🔍 **جستجوی پیشرفته فاکتور:** امکان جستجو در تاریخچه فاکتورها علاوه بر شماره و آیدی، بر اساس **نام مشتری**.
* ⚡ **افزودن سریع (Quick Add):** چیپست‌های افزودن سریع محصولات به فاکتور با قابلیت فیلتر شدن بر اساس دسته‌بندی انتخابی.
* 🖨️ **شخصی‌سازی چاپ فاکتور:** امکان تعریف **متن پاورقی (Footer Message)** اختصاصی برای هر فروشگاه در تنظیمات.
* 🗓️ **حالت تقویم ترکیبی (Both):** امکان نمایش همزمان تاریخ شمسی و میلادی در فاکتورها، گزارش‌ها و خروجی‌های چاپی.
* 🕒 **پشتیبانی از Timezoneهای جدید:** تنظیم خودکار ساعت زنده بر اساس مناطق زمانی **شانگهای (Asia/Shanghai)** و **مسکو (Europe/Moscow)**.
* ♿ **دسترسی‌پذیری (Accessibility):** پشتیبانی کامل از `prefers-reduced-motion` برای غیرفعال کردن انیمیشن‌ها جهت راحتی کاربران حساس.

## 🏗️ ساختار پروژه (نسخه 3.0)
برخلاف فریم‌ورک‌های سنگین MVC، این پروژه از یک معماری ساخت‌یافته و چابک پیروی می‌کند که نیاز به دیتابیس را حذف کرده است:

```text
/workspace
├── index.php           # فایل اصلی برنامه (Backend، API و Frontend یکپارچه)
└── rasa_data/          # پوشه ذخیره‌سازی داده‌ها (ایجاد شده به صورت خودکار)
    ├── .htaccess       # فایل امنیتی برای جلوگیری از دسترسی مستقیم وب
    ├── settings.json   # تنظیمات فروشگاه، زبان، پول، تم، مالیات و وضعیت نصب
    ├── categories.json # لیست دسته‌بندی‌ها
    ├── products.json   # لیست محصولات و موجودی انبار
    ├── invoice.json    # پیش‌نویس فاکتور فعلی (Draft)
    ├── sales.json      # تاریخچه کامل فروش‌ها و فاکتورهای ثبت شده
    ├── returns.json    # تاریخچه مرجوعی‌های کالا
    └── stock_moves.json# گزارش تراکنش‌های ورود/خروج انبار
```
