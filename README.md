# 🚀 درباره پروژه
## معرفی جامع
این پروژه یک سیستم پیشرفته و حرفه‌ای مبتنی بر معماری ساخت‌یافته (Structured Architecture) است که با هدف ایجاد ساختاری منظم، قابل نگهداری، مقیاس‌پذیر و مدرن توسعه یافته است. این اپلیکیشن سبک‌وزن PHP با رعایت اصول Clean Code و بهترین روش‌های برنامه‌نویسی طراحی شده است تا توسعه‌دهندگان و کسب‌وکارها بتوانند بدون نیاز به پایگاه‌داده‌های سنگین، به سرعت و با کیفیت بالا یک سیستم مدیریت فروش، انبارداری و مرجوعی قدرتمند را راه‌اندازی کنند.

## ✨ ویژگی‌های کلیدی
✅ **معماری ساخت‌یافته و یکپارچه:** جداسازی منطقی لایه‌های داده، API و رابط کاربری در یک ساختار منسجم و بدون پیچیدگی‌های اضافی
✅ **سیستم چندزبانه (i18n):** پشتیبانی کامل از ۶ زبان با تغییر خودکار چیدمان (RTL/LTR)
✅ **چند واحد پولی:** پشتیبانی از ۵ واحد پولی بین‌المللی با قابلیت قفل‌شدن پس از نصب
✅ **سیستم نصب‌کننده (Installer):** راه‌اندازی اولیه آسان و تعاملی
✅ **مدیریت مالی پیشرفته:** محاسبه خودکار مالیات بر ارزش افزوده (VAT) و تخفیف‌های درصدی/مبلغی
✅ **پشتیبانی از تم تاریک و روشن:** دارای قابلیت Dark Mode و Light Mode برای تجربه کاربری بهتر
✅ **ریسپانسیو و مدرن:** منوی ناوبری شناور (Island Nav) و منوی کناری (Side Island) سازگار با تمام دستگاه‌ها
✅ **سیستم جامع انبارداری:** مدیریت موجودی، ورود کالا، انبارگردانی و هشدار موجودی کم
✅ **اسکنر بارکد حرفه‌ای:** پشتیبانی از اسکن بارکد و QR Code با دوربین دستگاه
✅ **سیستم مرجوعی کالا:** امکان مرجوع کردن اقلام و بازگشت خودکار به موجودی انبار
✅ **مسدودسازی دستگاه‌های موبایل:** قابلیت محدود کردن دسترسی به پنل فقط برای دسکتاپ (ویژه 2.5)
✅ **ساعت و تقویم زنده:** نمایش ساعت و تاریخ بر اساس منطقه زمانی زبان انتخابی (ویژه 2.5)
✅ **اطلاعات دستگاه:** نمایش نوع دستگاه، سیستم‌عامل، مرورگر و وضوح صفحه (ویژه 2.5)
✅ **منوی کشویی موبایل (Drawer Menu):** منوی اختصاصی برای دستگاه‌های کوچک (ویژه 2.5)

## 📦 تاریخچه نسخه‌ها

### 🚀 نسخه 1.0 - نسخه پایه
**📅 تاریخ انتشار:** خرداد ۱۴۰۵
* معرفی ساختار اولیه و توابع کمکی
* پایه‌ریزی سیستم ذخیره‌سازی محلی (JSON)
* رعایت اصول SOLID و بهترین روش‌های برنامه‌نویسی
* پرفورمنس بهینه و کدنویسی تمیز

### 🎉 نسخه 1.7 - نسخه پیشرفته مدیریت فروشگاه
**📅 تاریخ انتشار:** ۲۸ مرداد ۱۴۰۵
* سیستم کامل مدیریت فروشگاه، دسته‌بندی‌ها و محصولات
* سیستم فاکتور فروش حرفه‌ای با محاسبه خودکار جمع و تخفیف
* تاریخچه، آمارگیر هوشمند (روز/هفته/ماه) و تقویم شمسی تعاملی
* رابط کاربری ریسپانسیو با تب‌بندی حرفه‌ای و انیمیشن‌های نرم

### 🌍 نسخه 2.0 - نسخه بین‌المللی و سازمانی
**📅 تاریخ انتشار:** شهریور ۱۴۰۵
* بومی‌سازی کامل (i18n) با ۶ زبان و تغییر خودکار RTL/LTR
* سیستم مالی پیشرفته (VAT، ۵ واحد پولی، تخفیف درصدی)
* ویزارد نصب اولیه (Installer) و سیستم پشتیبان‌گیری
* تولید آیدی و شماره سریال یکتای فاکتورها (RSA-ID / RSA-00000001)

### 🔥 نسخه 2.4 - نسخه انبارداری و هوشمند
**📅 تاریخ انتشار:** ۲۰ شهریور ۱۴۰۵
**طراح و توسعه‌دهنده:** آقای پابلو

✨ **قابلیت‌های انقلابی افزوده شده در نسخه 2.4:**
* 📦 **ماژول جامع انبارداری (Warehouse):** مدیریت موجودی، ورود کالا، انبارگردانی و سیستم هشدار موجودی کم.
* 📷 **اسکنر بارکد با دوربین:** اسکن بارکد و QR Code مستقیماً با دوربین در هنگام تعریف محصول و ثبت فاکتور.
* 🔄 **سیستم مدیریت مرجوعی (Returns):** مرجوع کردن اقلام فاکتور و بازگشت خودکار به چرخه انبار.
* 💾 **بازیابی پشتیبان پیشرفته (Restore):** بازیابی فایل پشتیبان با قابلیت Drag & Drop و انتخاب بخش‌ها.
* 📑 **خروجی گزارش‌ها به Excel (CSV):** دانلود گزارش‌های فروش با فرمت CSV و پشتیبانی کامل از UTF-8.
* 🎨 **ارتقای رابط کاربری (UI/UX):** افزودن منوی کناری (Side Island) برای دسترسی سریع به بخش‌های انبار و مرجوعی.

### 💎 نسخه 2.5 - نسخه امنیت دستگاه و تجربه کاربری (فعلی)
**📅 تاریخ انتشار:** ۲۶ تیر ۱۴۰۵
**طراح و توسعه‌دهنده:** آقای پابلو

✨ **قابلیت‌های جدید افزوده شده در نسخه 2.5:**
* 🔒 **مسدودسازی دستگاه‌های موبایل (Block Mobile):** قابلیت محدود کردن دسترسی به پنل فقط برای دستگاه‌های دسکتاپ. با فعال‌سازی این گزینه، کاربران موبایل و تبلت با پیام «لطفاً با دسکتاپ وارد شوید» مواجه می‌شوند.
* ⏰ **ساعت و تقویم زنده (Live Clock):** نمایش ساعت و تاریخ شمسی/میلادی به صورت زنده در هدر برنامه بر اساس منطقه زمانی زبان انتخابی (تهران، نیویورک، لندن، پاریس، برلین، مادرید).
* 📱 **اطلاعات دستگاه کاربر (Device Info):** نمایش نوع دستگاه (موبایل/تبلت/دسکتاپ)، سیستم‌عامل، مرورگر و وضوح صفحه نمایش در تنظیمات و منوی کشویی.
* 📲 **منوی کشویی موبایل (Mobile Drawer):** طراحی منوی اختصاصی و زیبا برای دستگاه‌های موبایل و تبلت با انیمیشن‌های روان و پشتیبانی از RTL/LTR.
* 🎨 **پس‌زمینه انیمیشنی (Orb Background):** افکت‌های بصری مدرن با حباب‌های متحرک و بلور شده در پس‌زمینه برای تجربه کاربری جذاب‌تر.
* 🔤 **فونت‌های وب حرفه‌ای:** استفاده از فونت‌های Vazirmatn (فارسی) و Inter (انگلیسی) از Google Fonts برای خوانایی بهتر.
* 🌐 **بهبود Timezone:** پشتیبانی دقیق از مناطق زمانی مختلف بر اساس زبان انتخابی کاربر.
* 🎯 **بهبود رابط کاربری:** ارتقای جزئیات بصری، سایه‌ها، گرادیان‌ها و انیمیشن‌ها برای تجربه مدرن‌تر.

## 🏗️ ساختار پروژه (نسخه 2.5)
برخلاف فریم‌ورک‌های سنگین MVC، این پروژه از یک معماری ساخت‌یافته و چابک پیروی می‌کند که نیاز به دیتابیس را حذف کرده است:

```text
/workspace
├── index.php           # فایل اصلی برنامه (Backend، API و Frontend یکپارچه)
└── rasa_data/          # پوشه ذخیره‌سازی داده‌ها (ایجاد شده به صورت خودکار)
    ├── .htaccess       # فایل امنیتی برای جلوگیری از دسترسی مستقیم وب
    ├── settings.json   # تنظیمات فروشگاه، زبان، پول، تم، مالیات و وضعیت نصب
    ├── categories.json # لیست دسته‌بندی‌ها
    ├── products.json   # لیست محصولات و موجودی انبار
    ├── invoice.json    # پیش‌نویس فاکتور فعلی (Draft)
    ├── sales.json      # تاریخچه کامل فروش‌ها و فاکتورهای ثبت شده
    ├── returns.json    # تاریخچه مرجوعی‌های کالا
    └── stock_moves.json# گزارش تراکنش‌های ورود/خروج انبار
```

## ⚖️ مجوز و حقوق
تمامی حقوق مادی و معنوی این پروژه متعلق به **آقای پابلو** می‌باشد. هرگونه کپی‌برداری، توزیع مجدد یا استفاده تجاری بدون اجازه کتبی طراح ممنوع است.
