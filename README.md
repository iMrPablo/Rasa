
## معرفی جامع
این پروژه یک سیستم پیشرفته و حرفه‌ای مبتنی بر معماری ساخت‌یافته (Structured Architecture) است که با هدف ایجاد ساختاری منظم، قابل نگهداری، مقیاس‌پذیر و مدرن توسعه یافته است. این اپلیکیشن سبک‌وزن PHP با رعایت اصول Clean Code و بهترین روش‌های برنامه‌نویسی طراحی شده است تا توسعه‌دهندگان و کسب‌وکارها بتوانند بدون نیاز به پایگاه‌داده‌های سنگین، به سرعت و با کیفیت بالا یک **سیستم مدیریت فروش و انبارداری** قدرتمند را راه‌اندازی کنند.

## ✨ ویژگی‌های کلیدی
✅ **معماری ساخت‌یافته و یکپارچه**: جداسازی منطقی لایه‌های داده، API و رابط کاربری در یک ساختار منسجم
✅ **سیستم جامع انبارداری**: مدیریت موجودی، ورود کالا، انبارگردانی و هشدار موجودی کم
✅ **اسکنر بارکد حرفه‌ای**: پشتیبانی از اسکن بارکد و QR Code با استفاده از دوربین دستگاه
✅ **سیستم چندزبانه (i18n)**: پشتیبانی کامل از ۶ زبان با تغییر خودکار چیدمان (RTL/LTR)
✅ **مدیریت مرجوعی کالا (Returns)**: امکان مرجوع کردن اقلام و بازگشت خودکار به موجودی انبار
✅ **سیستم مالی پیشرفته**: محاسبه خودکار مالیات بر ارزش افزوده (VAT) و تخفیف‌های درصدی/مبلغی
✅ **خروجی و گزارش‌گیری**: پشتیبان‌گیری/بازیابی با Drag & Drop و خروجی گزارش‌ها به CSV (Excel)
✅ **ریسپانسیو و مدرن**: منوی ناوبری شناور (Island Nav) و منوی کناری (Side Island) سازگار با تمام دستگاه‌ها

  * مدیریت موجودی انبار با قابلیت **ورود کالا (Receive)** و **انبارگردانی (Stock Count)**.
  * سیستم **هشدار موجودی کم (Low Stock Alert)** برای جلوگیری از اتمام کالا.
  * ثبت **تراکنش‌های انبار (Stock Moves)** با گزارش دقیق تاریخچه ورود، خروج، فروش و مرجوعی.
* 📷 **اسکنر بارکد با دوربین (Camera Scanner):**
  * افزودن کتابخانه `html5-qrcode` برای اسکن بارکد و QR Code مستقیماً با دوربین موبایل یا وب‌کم در هنگام تعریف محصول و ثبت فاکتور.
* 🔄 **سیستم مدیریت مرجوعی (Returns):**
  * امکان انتخاب فاکتور و مرجوع کردن اقلام آن.
  * بازگشت خودکار تعداد مرجوعی به موجودی انبار و ثبت در تراکنش‌ها.
* 💾 **سیستم پشتیبان‌گیری و بازیابی پیشرفته (Restore):**
  * امکان بازیابی فایل پشتیبان با قابلیت **Drag & Drop**.
  * انتخاب بخش‌های مورد نظر برای بازیابی (تنظیمات، دسته‌بندی‌ها، محصولات، فروش‌ها).
* 📑 **خروجی گزارش‌ها به Excel (CSV):**
  * امکان دانلود گزارش‌های فروش با فرمت CSV و پشتیبانی کامل از UTF-8 برای زبان فارسی.
* 🔍 **مدیریت هوشمند فاکتورها:**
  * جستجوی پیشرفته در تاریخچه فاکتورها.
  * قابلیت **بارگذاری مجدد فاکتور (Load Invoice)** در ویرایشگر برای ویرایش یا تکرار.
* 🎨 **ارتقای رابط کاربری (UI/UX):**
  * افزودن **منوی کناری (Side Island)** برای دسترسی سریع و شناور به بخش‌های انبار، مرجوعی و تراکنش‌ها.

## 🏗️ ساختار پروژه (نسخه 2.4)
برخلاف فریم‌ورک‌های سنگین MVC، این پروژه از یک معماری ساخت‌یافته و چابک پیروی می‌کند که نیاز به دیتابیس را حذف کرده است:

```text
/workspace
├── index.php           # فایل اصلی برنامه (Backend، API و Frontend یکپارچه)
└── rasa_data/          # پوشه ذخیره‌سازی داده‌ها (ایجاد شده به صورت خودکار)
    ├── .htaccess       # فایل امنیتی برای جلوگیری از دسترسی مستقیم وب
    ├── settings.json   # تنظیمات فروشگاه، زبان، پول، تم، مالیات و وضعیت نصب
    ├── categories.json # لیست دسته‌بندی‌ها
    ├── products.json   # لیست محصولات و موجودی انبار
    ├── invoice.json    # پیش‌نویس فاکتور فعلی (Draft)
    ├── sales.json      # تاریخچه کامل فروش‌ها و فاکتورهای ثبت شده
    ├── returns.json    # [جدید] تاریخچه مرجوعی‌های کالا
    └── stock_moves.json# [جدید] گزارش تراکنش‌های ورود/خروج انبار
```

## 🛡️ معماری ساخت‌یافته به تفصیل

💾 **لایه مدیریت داده (Data Layer)**
* استفاده از فایل‌های JSON برای ذخیره‌سازی سبک، سریع و بدون نیاز به Database.
* استفاده از `LOCK_EX` در PHP برای جلوگیری از تداخل در زمان خواندن و نوشتن همزمان (Concurrency Control).
* ایمن‌سازی پوشه داده‌ها با فایل `.htaccess` (Require all denied).

⚙️ **لایه منطق تجاری و API (Business Logic & API Layer)**
* توابع مجزا و بهینه برای محاسبات پیچیده تقویم جلالی و میلادی.
* مدیریت درخواست‌های AJAX از طریق یک Endpoint واحد (`?api=1`) با متدولوژی REST-like.
* پردازشگرهای اختصاصی برای انبارگردانی، کسر/افزایش موجودی و ثبت مرجوعی.

🎨 **لایه نمایش (Presentation Layer)**
* رابط کاربری تک‌صفحه‌ای (SPA-like) با استفاده از Vanilla JavaScript.
* سیستم ترجمه (i18n) پویا با استفاده از دیکشنری‌های JavaScript.
* استفاده از CSS Variables و Glassmorphism برای پیاده‌سازی بی‌نقص تم‌های تاریک و روشن و منوهای Island Nav.

## 💻 تکنولوژی‌های مورد استفاده
* **PHP 8+** - زبان برنامه‌نویسی سمت سرور
* **Structured Architecture** - الگوی طراحی معماری چابک
* **HTML5 & CSS3** - ساختار و استایل‌دهی (با CSS Variables و Glassmorphism)
* **Vanilla JavaScript (ES6+)** - تعاملات سمت کاربر و مدیریت State
* **Fetch API** - ارتباطات AJAX مدرن
* **HTML5-QRCode** - کتابخانه اسکن بارکد با دوربین
* **JSON Storage** - پایگاه داده سبک و فایل‌محور

## 📥 نصب و راه‌اندازی
1. آپلود فایل `index.php` روی هاست یا سرور محلی (نیاز به PHP 8+).
